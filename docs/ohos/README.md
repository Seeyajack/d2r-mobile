# docs/ohos/ —— 我们的文档

> 上游的 `docs/` 按 `docs/<主题>/日期-名字.md` + `.zh-CN.md` 双语成对存放。
> 我们的文档**不掺进去**，单独放这个子目录，理由：
> - 加在别人的目录里，万一上游以后建同名文件就撞车；独立子目录只增不改，`git merge upstream` 永远无冲突。
> - 我们只写中文，不必为了对齐上游去造 `.md` + `.zh-CN.md` 的空壳对。

## 约定

| 项 | 规则 |
|---|---|
| 文件名 | `<主题>-np<编号>.md`；编号 = 我们自己的推进轮次（np237、np241…） |
| 语言 | 中文 |
| 内容 | 方法沉淀、方案、定谳记录 —— **结论与依据都要在，不写流水账** |
| 不放这里 | 代码目录内的说明（就地 `README.md`）；按日的进度（在工作区的 `10-进度/`） |
