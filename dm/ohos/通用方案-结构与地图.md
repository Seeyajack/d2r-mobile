# 通用方案 · 结构图与地图（Switch → 鸿蒙移植框架）

> 定位（2026-10-15 确定）：目标是**一套通用的鸿蒙移植方案**——每个游戏的专属兼容层不同，
> 但骨架（装载、图形、音频、跑测、垫片）共通。
> 上游 **d2r-mobile** 项目降级为**参考实现**（它的宿主层是 D2R 专属的，是样本而非必移植件）；
> 测试载荷用**《塞尔达传说：旷野之息》**（转储完整、模拟器可交叉验证、模块已抽齐）。
>
> 本文是地图：每块是什么、状态如何、哪些要泛化。改一处，记得回来更新。

## 一、分层结构

```
┌──────────────────────────────────────────────────────────────────┐
│ L3 游戏专属层（每个游戏一套，不属于"通用方案"本体）                    │
│   D2R 参考实现：hle_fs/hle_audio/hle_oe/dm_hud/dm_pouch/…（上游）   │
│   BotW：待定义（如果未来真要跑 BotW 游戏本身，工作量为另一个项目级）    │
├──────────────────────────────────────────────────────────────────┤
│ L2 领域层：把游戏的"平台调用"翻译成宿主机制（通用机制，游戏只提供数据）    │
│   装载链：NSO 改写器 → 内嵌 → 运行时装载 → 执行（宿主门/线程槽）        │
│   图形链：NVN 命令回放 → Vulkan；贴图：解排布→解码→上传→采样；转码      │
│   音频链：downmix51 → OH Audio                                       │
├──────────────────────────────────────────────────────────────────┤
│ L1 通用平台层（与游戏完全无关）                                        │
│   Vulkan 后端（vk_backend/vk_ctx/swapchain/贴图/时间戳）              │
│   垫片层 compat（mach/fs/hash/str/dispatch/pthread-qos）             │
│   跑测框架（宿主单测收编 + 探针按钮 + 逐像素判据）                       │
│   诊断文化：hilog 报告、可验证判据、模拟器日志验明正身、截图不可信        │
└──────────────────────────────────────────────────────────────────┘
```

**通用 vs 专属的判据**：换一个游戏（换编译器、换引擎、换资源格式）之后，**不需要改**的算通用件；
需要按游戏重写/重登记的算专属层。任何"写死了某个游戏假设"的通用件，都要登记到 §四 泛化清单。

## 五、当前任务方案：改写器泛化（跳转表识别）——待批

**问题**：改写器要处理游戏代码里的每一条 `br x18`（间接跳转）。D2R 的编译器输出惯用法是：
`adr x18, <表>` → 索引装载（`ldrb/ldrh`）→ `add x18, x18, idx, lsl #2` → `br x18`，
且都在**前 8 条**里。旷野之息的编译器（更新的 clang）产的序列不同，识别失败即 assert 中止
（中止本身是对的：识别错会静默产出错误代码，比失败危险得多）。

**方案（C 混合式，两步走）**：
1. **模式族扩展**（保守）：把识别的"上下文窗口"从 8 条放宽，并补齐 aarch64 的 switch 惯用法族：
   - 基址：`adr xN` 之外，补 `adrp xM,页; add x18,xM,#off` 组合；
   - 索引：`ldrb/ldrh` 之外，补 `ldrsw/ldr`（有符号/32 位）；缩放 `lsl #2` 之外补 `lsl #3`（8 字节条目）与"无缩放"；
   - 寄存器：基址/索引不限定 x18（先入其他寄存器再 `mov x18` 的组合）。
2. **识别失败不中止**：改为**登记 + 继续**——把该 `br x18` 原样保留、记入 `<名>.unresolved.tsv`，
   最后在报告里**逐条列出**（含地址与上下文反汇编）。安全前提：鸿蒙侧 x18 若不被内核改写，原样保留
   **行为可能对**（待实测确认）；即使行为错，也是"可见的错"，不是"静默的错"。
3. **验收判据**：对旷野之息 main 跑完改写**不中止**；`unresolved.tsv` 每条都有反汇编上下文；
   抽查 N 条已识别跳转表的 (基址,宽度) 与手工反汇编一致。

**工作量预估**：识别逻辑改造 + 报告，约半天；不确定性在模式族覆盖度（遇到新形态再补是常态）。
